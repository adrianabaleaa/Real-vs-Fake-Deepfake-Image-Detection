# Deepfake Face Detector: Real vs. AI-Generated

An Artificial Intelligence computer vision project designed to detect whether a human face is authentic (real) or generated by AI (deepfake). The project utilizes Deep Learning, specifically Transfer Learning with the **EfficientNetB0** architecture, and includes real-time webcam testing capabilities via OpenCV.

## Dataset & Training
The model was trained on the [140k Real and Fake Faces Dataset](https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces), consisting of:
* **70,000 Real Faces:** Sourced from Flickr (Flickr-Faces-HQ dataset).
* **70,000 Fake Faces:** Generated using Generative Adversarial Networks (StyleGAN/ProGAN).

By training on a perfectly balanced dataset, the neural network learned to identify microscopic digital artifacts, asymmetrical features, and texture inconsistencies specific to GAN-generated media.

## Model Architecture & Performance
* **Base Model:** EfficientNetB0 (pre-trained on ImageNet).
* **Custom Top Layers:** GlobalAveragePooling2D -> Dropout (0.5) -> Dense (Sigmoid activation).
* **Test Accuracy:** **81.28%** on previously unseen data (In-Distribution).
* **Loss:** 0.4139

## Key Findings & Limitations (Domain Shift)
While the model performs exceptionally well at identifying artifacts from earlier GAN architectures (like ProGAN or StyleGAN1/2), it highlights a classic **Domain Shift** vulnerability in Machine Learning. 

During manual adversarial testing, the model struggled to detect fake faces generated by modern **Diffusion Models** (e.g., Midjourney, DALL-E 3) and **StyleGAN3**. This proves that as AI image generation evolves to become alias-free and mathematically perfect, detection models must constantly be retrained on new distributions of data.

## Features
1. **Live Webcam Testing ("Snap & Test"):** Use your laptop's camera to take a snapshot and run the AI analysis instantly.
2. **Static Image Testing:** Run the detector on saved `.jpg` or `.png` files.
3. **Dynamic Path Mapping:** Built-in `os` path handling allows the scripts to run perfectly on any machine as long as the model file is in the same directory.
